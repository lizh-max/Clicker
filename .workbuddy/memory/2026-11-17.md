# 2026-11-17 连点器项目（下午）

## 修复「点击启动直接关闭悬浮球」
用户反馈：点击启动后悬浮球直接关闭（整个球+面板消失）。

### 根因定位（两个）
1. **空任务默认点位残留**：`ClickTask` 默认值 `steps = listOf(Step(StepType.TAP))`（坐标默认 0,0），
   且 `taskFromJson` 有兜底 `if (steps.isEmpty()) steps.add(Step(StepType.TAP))`。
   导致空任务时 `startClicking()` 的 `steps.isEmpty()` 检查失效，直接 dispatchGesture 点击屏幕左上角 (0,0)，
   干扰悬浮窗且任务行为异常。
2. **通知 small icon 用彩色 vector**：`setSmallIcon(R.drawable.ic_ball)` 用了含蓝底+白路的彩色 vector，
   作为通知栏 small icon 在部分设备渲染异常/抛异常，导致 startForeground 失败 → 服务崩溃 → 悬浮球消失。

### 修复
1. `ClickTask.kt`：默认 steps 改为 emptyList()；删除 taskFromJson 的 `steps.isEmpty()` 兜底塞点逻辑。
2. `FloatingBallService.kt`：通知 setSmallIcon 改用新建的单色 alpha 图标 `ic_notification`（圆环）。
3. 新建 `res/drawable/ic_notification.xml`：纯白色圆环（evenOdd 挖空），符合通知栏 alpha 图标规范。

### 注意
- 无连接设备，未能抓取 logcat 精确定位崩溃栈；以上为代码逻辑推理的最可能根因。
- 建议用户在真机复现时若仍关闭，用 `adb logcat | grep AndroidRuntime` 抓崩溃栈反馈。
