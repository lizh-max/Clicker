# 2026-11-16 连点器项目

## 项目概述
安卓连点器：离线、零 root、最小权限（仅 SYSTEM_ALERT_WINDOW）。Kotlin + AccessibilityService + 悬浮窗，minSdk 24 / targetSdk 34。
